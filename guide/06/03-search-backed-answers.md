# Search-backed answers and the links

<!-- index: 9#10, 9#11, 9#5, 9#4, 9#15 -->

Some responses come with sources cited. This section is about what a
citation in a response is, and is not, evidence of.

## With and without search

OpenAI's page distinguishes two cases. Without search enabled, responses
are based on what the model learned during training; with search or deep
research, the model can access and cite real-time web sources to answer
with more recent information. The difference matters because of the
knowledge cutoff lesson 1 described: the page says responses do not
incorporate information about events beyond the point the model was
trained to, unless tools are used. A search-backed answer, then, is the
case in which a response can be newer than the model.

## Follow the link

The page's advice for this case is specific: use available tools like
search or deep research, and check sources when accuracy matters by
visiting links directly. The last three words are the practice. Lesson 1
listed fabricated citations and references to non-existent sources among
the forms of hallucination the page names, and the page's advice here is
the answer to it: the link is visited, and the source is read. What the
response says the source says is then checked against what the source
says.

## When the link cannot be followed

The page lists lack of access among the model's limitations: it may not
be able to obtain relevant information from a given website because of
technical issues, paywalls, or preferences a site sets through its
robots.txt file. That limitation runs the other way from the previous
one. A source the model could not read is not one the response can have
drawn on, whatever the response says about it. For a CPA the practical
consequence is the same as before: the document is opened, and what is
relied on is what it says.

## Search is not verification

Search changes where a response comes from; it does not change what the
page says to do with the response. The first-draft rule of section 01
applies to a cited answer as much as to an uncited one, and the four
items of section 02 are checked the same way whether or not a link came
with them. What search adds is a place to start, and a link to follow.
Which plans include search, and what "deep research" is beyond the
page's name for it, is not something this lesson says.

# Asking for verbatim excerpts

<!-- index: 4#7, 4#10 -->

Everything so far has been about getting a better answer. This section is
about getting an answer that can be checked.

## The toolkit's practice

The CPA.com toolkit describes a research use of the tool in which the
model is asked not for a conclusion but for the passages a conclusion
would rest on. It says that by prompting the model to return verbatim
excerpts, you can mimic the way a human researcher gathers information in
order to reach conclusions more efficiently. A prompt of that kind asks
for the excerpts with a citation to where each one sits in the document,
so that the reader checks the source and not the summary.

A prompt of that kind might read: "Attached is the text of the document.
I am researching the one question stated below. In a bullet list, give
the most relevant verbatim excerpts, each with a citation to the section
it comes from." Nothing in that prompt asks the model what the document
means.

## Why verbatim

The word that does the work is *verbatim*. The reason is the one the
toolkit gives: the human reaches the conclusion, and the model gathers
the passages. A summary would have to be taken on trust; an excerpt with
a citation is either found in the document at the cited place or it is
not, and lesson 1 said what to make of a citation that cannot be found.

## When to use it

The practice applies whenever the answer is going to be checked against a
document the model has been given. Lesson 4 says when that is, and its
rule is short: anything that will be relied on. For a question about
what a document says, then, the prompt asks for the excerpts, and the
CPA reads them in the document.

## What goes in with the prompt

The practice depends on the model having the document, and the toolkit
attaches one condition to its own examples of that kind: any example
that references uploading data requires all identifiable information to
be removed prior to use. The toolkit says that of its own use cases, and
lesson 5 is about the rule behind it. Whether a document can be uploaded
at all, and how much of one, depends on the plan, and that is section
06's subject.

# sources/asc842 — index

Source material for course ASC842-PCX, "ASC 842 for Private Companies: The
Practical Expedients." The `.txt` Codification files are paragraphs copied
verbatim from the current Codification at asc.fasb.org; the ASU `.txt` files
are text extractions of the PDFs beside them (pypdf, layout not preserved —
page headers and line breaks intrude, so quote from the PDF when exact
wording matters). Only files marked **authoritative** may support a claim in
a lesson; the other two are context.

Where an ASU and a Codification `.txt` cover the same paragraph, the
Codification file is the text of record: the ASU shows the paragraph as
issued, the Codification shows it as it stands today.

## Notes

**"Class of underlying asset" has no standalone definition.** The phrase is
used throughout Topic 842 (842-20-25-2 and 842-20-30-3 both make elections
"by class of underlying asset") without a glossary entry. Lessons should
treat it at face value — a grouping of assets of similar nature and use —
and should not promise a definition the Codification does not give.
